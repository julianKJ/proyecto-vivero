Sistema Inteligente para la Gestión de Viveros

Optimiza el control de inventarios, plantas ornamentales, abonos, clientes mayoristas y proveedores en una sola plataforma web integrada.

Acceder al Sistema

Módulos Principales del Sistema

Gestión de Inventario

Control detallado de existencias, precios y categorías para plantas, abonos y sustratos con operaciones CRUD completas.

Clientes Mayoristas

Registro y seguimiento de compradores frecuentes y mayoristas con validación de datos de contacto.

Proveedores

Administración centralizada de proveedores de insumos, facilitando la reposición oportuna de mercancía.

Empleados y Seguridad

Control de acceso seguro mediante autenticación (Login) y encriptación de contraseñas para el personal autorizado.

Tecnologías Utilizadas

Python & Flask
HTML5 & CSS3
Base de Datos Relacional (SQLite / MySQL)
Control de Versiones (Git)
